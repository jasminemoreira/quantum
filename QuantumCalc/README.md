# Quantum Calculator

A single-file, offline, didactic **symbolic quantum-state calculator** — a scientific-calculator-style
keypad for the **algebraic manipulation** of quantum circuits, with an **exact** core (ℤ[ζ₁₆] over BigInt:
fractions, √2, π/8 phases, e^{iθ}) and a **symbolic** engine for abstract kets `|ψ⟩`.

**Live:** https://jasminemoreira.com.br/quantum/ — served over HTTPS, so it is installable as a PWA
(Install / Add to Home screen) and works offline after the first visit.

## Files

| File | Role |
|---|---|
| `quantum_calc.html` | The application (single file, runs from `file://` or over http). |
| `manual.html` | The manual: **Part I — Reference** + **Part II — Cookbook** (26 worked examples). Generated by the test pipeline. |
| `manifest.webmanifest`, `sw.js`, `icons/icon.svg` | PWA assets (App Shell). |
| `vendor/katex/` | Vendored KaTeX (offline math rendering for `manual.html`). |
| `tests/` | Phase 6 test suites (not part of the deliverable). |

## Two ways to run

### 1. Share the file (no server)
Open `quantum_calc.html` directly in a browser (`file://`). Everything works offline; the manual opens via
the **📖 manual ↗** link. The service worker does **not** run from `file://` (by design) — registration is
guarded by `location.protocol`, so opening the file directly behaves like a plain page.

### 2. Install as a PWA (requires http/https)
Service workers only run over **http/https** (or `localhost`). To make the app installable and cache-backed
offline:

```sh
# from this directory, any static server works, e.g.:
python3 -m http.server 8000
# then open http://localhost:8000/quantum_calc.html and use the browser's "Install" / "Add to Home screen"
```

For public hosting, serve the folder over **https** (e.g. GitHub Pages). All PWA paths are **relative** (`./`),
so a project subpath (e.g. `https://user.github.io/QuantumCalc/`) works without changes. The service worker
(`qcalc-v10-10`) precaches the entry points and caches the rest (KaTeX, fonts) on first online visit, then serves
cache-first for offline use. **Bump the `CACHE` name in `sw.js` whenever you redeploy changed files** — the old
cache is purged on activation, so installed PWAs pick up the update on their next visit.

> Note (iOS Safari): installed PWAs have no push and may evict storage — irrelevant for this offline didactic
> calculator. The icon (`icons/icon.svg`) is a maskable SVG you can replace with your own.

## Generating the manual

`manual.html` is produced from the single source `tests/examples-data.mjs` by the Playwright pipeline
(`tests/examples.spec.js` → `tests/examples-render.mjs`), which replays each example on the real interface and
captures the on-screen result. From `tests/`:

```sh
npm install
npx playwright test examples.spec.js   # regenerates manual.html
```
